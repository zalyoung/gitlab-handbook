## Input

Input in this context refers to the information provided to the tool to generate a response. This includes text copied or typed directly into the tool’s user interface and uploaded files.

Do not submit [personal data like names, photographs of individuals, contact information, customer data, or otherwise confidential information] as input to the tools. _[Note: Depending on the vendor terms, AI vendors may have the right to view and/or train AI models using tool inputs. Amend this provision as appropriate to protect inputs from such use by vendors.]_ Only submit input that you legally obtained and have the rights to use. If unsure whether a particular type of data can be used as input, reach out to [the team responsible for these guidelines].

## Output

Output refers to the content generated by an AI tool in response to the input provided. Output can include text, images, audio, code, numerical data, and other content.

Output from generative AI tools used in work product requires the same careful review as manually-created work product. This helps identify and address instances of ‘hallucination’, the phenomenon where AI tools generate output that is plausible but factually incorrect or nonsensical. It is recommended that factual output used in work product (including citations, statistics, and quotes) is validated with first-hand information or a third-party, trustworthy source. Further guidance on reducing hallucinations can be found in [this Anthropic user guide](https://docs.anthropic.com/en/docs/test-and-evaluate/strengthen-guardrails/reduce-hallucinations)_[add link to alternative guidance on tips to reduce hallucinations]_.

When using these tools, be mindful of output that might be harmful. In particular, look out for misleading output, and output that contains personal data not intended for disclosure. Similarly, keep in mind that sometimes AI tools may generate output that creates or perpetuates unfair biases. [This article](https://www.ibm.com/think/topics/shedding-light-on-ai-bias-with-real-world-examples) provides useful examples of biased generative AI outputs to watch out for.

Generative AI tools should not be used as a substitute for obtaining input, advice, and approval from [the team responsible for providing legal advice], including in the context of the interpretation of laws, regulations, and contracts.

## Attribution of published content

When publishing AI-generated content (including in blog posts), disclose AI involvement. For example, if a blog post is co-authored with AI, include a statement at the bottom of the post saying “AI-generated content: Some content on this page was generated with the assistance of AI tools. All AI-generated content has been reviewed, edited, and validated by a human author.”
