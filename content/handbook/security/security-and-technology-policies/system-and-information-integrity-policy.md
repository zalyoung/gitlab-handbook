title: "System and Information Integrity Policy"
---

Policy and Procedures
1.1. The organization develops, documents, and disseminates system and information integrity policies and procedures. (SI-1)
1.2. System and information integrity policies and procedures are reviewed and updated annually or when significant changes occur. (SI-1)


System Monitoring
2.1. The organization monitors information systems to detect attacks and indicators of potential attacks. (SI-4)
2.2. Automated tools are employed to support near real-time analysis of events. (SI-4(2))
2.3. Monitoring information is correlated from multiple sources and sensors. (SI-4(16))


Flaw Remediation
3.1. The organization identifies, reports, and corrects information system flaws. (SI-2)
3.2. Security-relevant software updates are installed within organization-defined time periods. (SI-2)
3.3. Flaw remediation is incorporated into the organizational configuration management process. (SI-2(6))


Malicious Code Protection
4.1. The organization employs malicious code protection mechanisms at information system entry and exit points. (SI-3)
4.2. Malicious code protection mechanisms are updated automatically. (SI-3(2))
4.3. The organization addresses the receipt of false positives and the resulting potential impact on the availability of the information system. (SI-3(8))


Information Handling and Retention
5.1. The organization handles and retains information within the information system and information output in accordance with applicable laws and organizational policy. (SI-12)
5.2. The organization implements automated mechanisms for digital media sanitization prior to disposal, release, or reuse. (SI-12(1))


Memory Protection
6.1. The information system implements security safeguards to protect its memory from unauthorized code execution. (SI-16)


Information Output Filtering
7.1. The information system validates information output to ensure that the information is consistent with the expected content. (SI-15)


Software, Firmware, and Information Integrity
8.1. The organization employs integrity verification tools to detect unauthorized changes to software, firmware, and information. (SI-7)
8.2. The organization performs integrity scans of the information system on a scheduled basis. (SI-7(1))


Spam Protection
9.1. The organization employs spam protection mechanisms at information system entry and exit points. (SI-8)
9.2. Spam protection mechanisms are updated automatically. (SI-8(2))


Information Input Validation
10.1. The information system checks the validity of information inputs. (SI-10)
10.2. The organization ensures that input validation errors are reviewed and resolved within an organization-defined time period. (SI-10(5))"""
