## Overview

Laptop wipes must be performed by [scheduling an appointment](#schedule-a-wipe) with an IT analyst. If GitLab discovers that a device has not been wiped according to policy, GitLab may act to enforce a remote lock/wipe without notice.

Laptops are wiped using [Jamf](/handbook/security/corporate/systems/jamf) for macOS, and [Fleet](https://internal.gitlab.com/handbook/security/corporate/tooling/fleet/#remote-wipe-controls) for Linux. Using these tools ensures a clean disk wipe is performed and GitLab can retain evidence of the disk wipe.

**Under no circumstance should you perform your own disk wipe** unless you are doing so at the request of IT to troubleshoot a technical problem with the laptop.
